## [0.1.0] — Phase 0: anchor & scaffold

### Added
- `QUALITY-BAR.md` — the highest rule: cited, measurable production-grade **native Android** standard (architecture, data, API/contract + concurrency, security + auth, UI + accessibility, testing, tooling/build/release, delivery/code-quality).
- `CONVENTIONS.md` — authoring rules: three-tier invariant, single-target model, reference-doc format (grep-addressable Terms), component model, naming, governance.
- `golden-tasks/` — the frozen Android benchmark tasks + scoring rubric.
- `docs/evaluation/` + `docs/initiatives/` — governance logs, seeded.
- Repo skeleton (`lib/process`, `lib/android/*`, `lib/cross-cutting/*`, `reference/`, `scripts/`).
- `README.md`, `VERSION` (0.1.0).

### Notes
- Differentiated by specializing **native Android only**, with a deeper reference corpus and an app-first pipeline.
- The corpus, skills and workers were written ahead of use, against the repo's own "extract, don't predict" rule. They are therefore **unvalidated** until golden-task GT-A1 runs; treat the impl references as drafts, not settled truth, until then.
