## [0.1.0] — Phase 0: anchor & scaffold

### Added
- `QUALITY-BAR.md` — the highest rule: cited, measurable production-grade **native Android** standard (architecture, data, API/contract, security + auth, observability, testing, Compose performance/a11y, release readiness, delivery/code-quality).
- `CONVENTIONS.md` — authoring rules: three-tier invariant, single-target model, reference-doc format (grep-addressable Terms), component model, naming, governance.
- `golden-tasks/` — the frozen Android benchmark tasks + scoring rubric.
- `docs/evaluation/` + `docs/initiatives/` — governance logs, seeded.
- Repo skeleton (`lib/process`, `lib/android/*`, `lib/cross-cutting/*`, `reference/`, `scripts/`).
- `README.md`, `VERSION` (0.1.0).

### Notes
- No agents, skills, or reference content yet — built from real friction starting Phase 1 (extract, don't predict).
- Differentiated from full-stack CRUISE by specializing **native Android only**, with a deeper reference corpus and an app-first "reap" pipeline for portfolio generation.
